# Задача 02 — печать через const-ссылки

Файл решения: `task-02-print-const-ref.cpp` (создаёшь сам, здесь только постановка).
Темы: параграф 2.6 — `vector`, range-for, `const auto&`, копии vs ссылки.
Фундамент для задач 03–06, где появятся указатели и функции.

## Что сделать

1. Скопируй `enum class Category` и `struct Product` из задачи 01
   в новый файл (каждый `.cpp` — отдельная программа, общего хедера нет).
2. В `main()`:
   - создай `std::vector<Product> catalog` из 3–4 товаров (микс обычной
     и designated инициализации из задачи 01);
   - выведи весь каталог циклом только в форме
     `for (const auto& p : catalog)` — без копий;
   - для каждого товара печатай в одну строку: `name | price | qty | cat-as-int`
     (`cat` печатай через `static_cast<int>`, как в задаче 01);
   - поменяй одно поле одного элемента через `catalog[i].price = ...`
     или `catalog.front().qty = ...` и выведи каталог ещё раз,
     чтобы было видно изменение.
3. Программа без ввода: просто создаёт вектор и печатает список 2 раза.
   Ввод и команды появятся в задаче 06.

## Требования

- `#include <iostream>`, `#include <string>`, `#include <vector>`. Больше ничего.
- Весь код — в `main()`, отдельных функций пока нет (функции начнутся с задачи 03).
- Никаких `auto p : catalog` (копия) и `auto&` без `const` в цикле печати —
  только `const auto&`. Изменение — отдельной строкой вне цикла печати.
- Никаких классов, заголовков, CMake — один файл с `main()`, как остальные
  задачи в репо.

## Проверка

```bash
clang++ -std=c++20 -O2 -Wall -Wextra -o /tmp/task02 projects/shop-catalog/task-02-print-const-ref.cpp && /tmp/task02
```

Приёмка:
- [ ] компилируется без варнингов с флагами выше;
- [ ] в коде печати нет копий (`const auto&`, нет `auto p`);
- [ ] каталог из 3+ товаров, печать в виде таблицы, видно изменение после правки;
- [ ] `static_cast<int>` для категории использован.

## Подсказки (не решение)

- `for (const auto& p : catalog) { ... p.name ... }` — `p` это ссылка,
  копии `std::string` не происходит.
- Чтобы показать разницу, можешь временно заменить на `for (auto p : catalog)`
  и подумать, что скопируется на каждой итерации — но в сданном файле
  оставь только вариант с `const&`.
- Формат строки на свой вкус, например:
  `Chicken | 499.9 | 15 | 0`.

Когда будет готово — кидай файл, разберём и дам задачу 03.
