# Задача 05 — pair/tuple + structured binding

Файл решения: `task-05-stats-pair-tuple.cpp` (создаёшь сам, здесь только постановка).
Темы: параграф 2.5 — `pair`, `tuple`, структурированное привязка `auto [total, qty] = ...`, `std::get<>`.
Фундамент для задач 06–07, где появятся функции, возвращающие составные типы.

## Что сделать

1. Скопируй `enum class Category` и `struct Product` из задачи 03.
2. В `main()`:
   - создай `std::vector<Product> catalog` из 3–4 товаров;
   - напиши функцию (или код внутри `main`) `stats`, которая принимает `catalog` и возвращает `std::pair<double, int>`: сумма `price * qty` по всем товарам и общая `qty`;
   - используй структурированное привязку `auto [total, qty] = stats(catalog);` для распаковки результата;
   - альтернативно покажи `std::get<0>(result)` и `std::get<1>(result)`;
   - выведи `total` и `qty` в одну строку.
3. В комментарии одной строкой: в чем отличие `std::pair` от `std::tuple` с точки зрения структурированной привязки (можно ли использовать `auto [a, b, c] = tuple`).
4. Программа без ввода: создаёт каталог, считает_stats, печатает результат.

## Требования

- `#include <iostream>`, `#include <string>`, `#include <vector>`, `#include <utility>` (для `pair`/`tuple`). Больше ничего.
- Функция `stats` обязательна, возврат `std::pair<double, int>`.
- Структурированная привязка `auto [total, qty] = ...` должна быть в коде.
- Оба способа доступа к значениям: через структурированную привязку и через `std::get<>`.
- Никаких классов, заголовков, CMake — один файл с `main()`.

- `price * qty` может переполнить `int`, сумму лучше посчитать в `double`.

- Structured binding работает и с `pair`/`tuple`/`array`.
