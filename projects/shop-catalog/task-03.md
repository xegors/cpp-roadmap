# Задача 03 — поиск указателями

Файл решения: `task-03-find-pointer.cpp` (создаёшь сам, здесь только постановка).
Темы: параграф 2.6 (упор) + первое забегание в 2.7 — `Product*`, `const Product*`,
`nullptr`, `->`, `*`, `const Product*` vs `Product* const`.

## Что сделать

1. Скопируй `enum class Category` и `struct Product` из задачи 02.
2. Напиши две функции (первый раз выносим код из `main`):
   ```cpp
   Product* findByName(std::vector<Product>& catalog, const std::string& name);
   const Product* findByNameConst(const std::vector<Product>& catalog, const std::string& name);
   ```
   - цикл внутри — по индексу или итератору, верни `&catalog[i]` / `&p` при совпадении `p.name == name`;
   - если не найдено — верни `nullptr`;
   - в `findByNameConst` каталог и возврат — `const`, менять через него нельзя.
3. В `main()`:
   - создай `catalog` из 3–4 товаров (как в задаче 02);
   - найди существующий товар через `findByName`, проверь `if (p != nullptr)`,
     напечатай через `p->name`, `p->price` (именно стрелку);
   - найди несуществующий товар, покажи ветку `nullptr` (печать `not found`);
   - вызови `findByNameConst` и напечатай через `(*p).name` (именно `*` + точка),
     чтобы обе формы доступа были в коде;
   - в комментарии одной строкой объясни разницу `const Product*` vs `Product* const`.
4. Программа без ввода: создаёт каталог, делает 3 поиска, печатает результаты.

## Требования

- `#include <iostream>`, `#include <string>`, `#include <vector>`. Больше ничего.
- Обе функции обязательны, сигнатуры — как выше.
- В `main` обязательны: проверка на `nullptr`, один доступ через `->`,
  один через `(*p).`, один вызов const-версии.
- Никаких классов, заголовков, CMake — один файл с `main()`.

## Подсказки (не решение)

- `&catalog[i]` — адрес элемента вектора, он жив пока жив вектор и не было
  `push_back` с реаллокацией — здесь каталог фиксированный, безопасно.
- `const Product*` — нельзя менять сам товар; `Product* const` — нельзя менять
  сам указатель. В сигнатуре нужен первый вариант.
- Не храни указатель после `push_back`/`erase` — в задаче 04-06 это выстрелит.
