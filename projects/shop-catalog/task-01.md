# Задача 01 — struct + enum

Файл решения: `task-01-struct-enum.cpp` (создаёшь сам, здесь только постановка).
Темы: параграф 2.5 — `enum class`, `struct`, designated initializers,
`sizeof`/выравнивание. Указателей тут почти нет, это фундамент для задач 02–06.

## Что сделать

1. Объяви `enum class Category` с 4 значениями на свой выбор,
   например еда / одежда / электроника / книги.
2. Объяви `struct Product` с полями:
   - `std::string name;`
   - `double price = 0.0;`
   - `int qty = 0;`
   - `Category cat;`
3. В `main()`:
   - создай один товар обычным агрегатным списком `{...}`;
   - создай второй товар через designated initializers `{ .name = ..., ... }`
     (порядок полей — как в объявлении struct);
   - поменяй одно поле через точку (`p.price = ...`);
   - преобразуй категорию в `int` и обратно через `static_cast`
     (туда-обратно, напечатай оба значения);
   - напечатай `sizeof` каждого поля по отдельности и `sizeof(Product)`,
     в комментарии рядом с выводом напиши, совпала ли сумма с размером
     структуры и почему (одна строка про выравнивание).
4. Программа без ввода: просто создаёт товары и печатает 5–7 строк.
   Это нормально, ввод появится в задаче 02.

## Требования

- Только `#include <iostream>`, `#include <string>`. `vector`, ссылки,
  указатели, `pair`/`tuple` — не нужны, они в следующих задачах.
- Не выноси ничего в отдельные функции (забегание в 2.7 начнётся с задачи 03).
  Весь код — в `main()`.
- Никаких классов, заголовков, CMake — один файл с `main()`, как остальные
  задачи в репо.

## Подсказки (не решение)

- Порядок в `{ .name = ..., .price = ..., .qty = ..., .cat = ... }`
  должен совпадать с порядком в `struct`, иначе ошибка компиляции.
- Пропущенные поля при designated init получат значения по умолчанию.
- `Color::White == 0` в хендбуке — аналогично нулевое значение твоего
  `enum class` получишь через `static_cast<Category>(0)`.
